# Макар Шулер — Portfolio

Учебный сайт-визитка/портфолио на **чистом HTML + CSS**.

## Реализовано

- Semantic HTML5: `header`, `nav`, `main`, `section`, `article`, `aside`, `form`, `footer`.
- CSS Grid для основной структуры.
- Flexbox для компонентов.
- Mobile-first + адаптивность.
- Видимый `:focus-visible` для клавиатурной навигации.
- Skip-link.
- Нативная HTML-валидация формы.
- CSS-only интерактивность: Hard/Soft Skills, Journey, `details/summary`, горизонтальные галереи и scroll-snap.
- JavaScript, фреймворки и библиотеки не используются.

## Перед сдачей

Проверь 360, 768 и 1280 CSS px, масштаб 200%, клавиатурную навигацию и видимый фокус. Убедись, что GitHub Pages правильно отдаёт файлы с пробелами/кириллицей в путях. При необходимости замени реальные контакты учебными.

## Ссылки проектов

Сейчас кнопки проектов временно ведут на общий GitHub-профиль. После публикации отдельных репозиториев замени `href` на соответствующие URL.

## Существенное использование ИИ

ИИ использовался для проектирования структуры, генерации и ревью HTML/CSS, улучшения текстов и проверки адаптивной/доступной структуры. Финальная проверка путей к изображениям, публикации и поведения страницы выполняется вручную.
