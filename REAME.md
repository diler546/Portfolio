# Макар Шулер — Portfolio

Персональный одностраничный сайт-портфолио программиста.

Сайт создан для представления информации обо мне, моих навыках, проектах и образовании.

## О проекте

Это адаптивный персональный сайт с тёмной минималистичной визуальной концепцией и фиолетовым акцентом.

Основная задача проекта — создать современное портфолио без использования JavaScript и сторонних фреймворков.

Сайт содержит:

- информацию обо мне;
- технические навыки;
- проекты;
- образование;
- практический опыт;
- контактную форму;
- ссылки на GitHub и другие контакты.

## Технологии

Проект полностью создан на:

- **HTML5**
- **CSS3**

В проекте используются:

- CSS Grid;
- Flexbox;
- CSS Media Queries;
- семантическая HTML5-разметка;
- CSS transitions и hover-эффекты;
- адаптивная вёрстка.

JavaScript, фреймворки и сторонние библиотеки не используются.

## Адаптивность

Сайт адаптирован для:

- Desktop;
- Tablet;
- Mobile.

Основные элементы страницы перестраиваются в зависимости от ширины экрана, а сетки проектов, навыков и других блоков адаптируются под мобильные устройства.

## Запуск

Проект не требует сборки или установки зависимостей.

Достаточно открыть:

```text
index.html
```

в браузере.

Для локальной разработки можно использовать любой простой локальный HTTP-сервер.

Например, через VS Code с расширением Live Server.
